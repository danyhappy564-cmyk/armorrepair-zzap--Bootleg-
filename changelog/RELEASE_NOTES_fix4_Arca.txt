원본 모드 : https://arca.live/b/tarkovspt/179689279

저는 SPT 4.1.5에서 돌아가게 고쳐 쓰는 비공식 포팅 버전이고, 원작자분 요청이 있으면 바로 내리겠습니다.
이 포팅 버전 문제는 원작자분께 문의하지 말아 주세요.

다운로드 (GitHub 릴리즈): https://github.com/danyhappy564-cmyk/armorrepair-zzap--Bootleg-/releases/tag/fix4


■ 어떤 모드인가요

레이드 중에 J 키를 누르고 있으면 입고 있는 방어구(방탄복·전술조끼·헬멧, 방탄판 포함)를 수리합니다.
가방·조끼·주머니·보안 컨테이너에 있는 방어구 수리 키트 자원을 씁니다.
지력 스킬이 높을수록 더 많이 고치고, 최대내구도도 덜 깎입니다.


■ 설치

- RaidArmorRepair.dll → SPT\BepInEx\plugins\ 에 덮어쓰기
- 서버 모드(야전 수리 키트)는 지난 버전(fix3)과 같습니다. 이미 깔려 있으면 그대로 두시면 됩니다.
- 설정 파일은 지우지 않아도 됩니다.


■ 이번에 바뀐 것 (지난 fix3 이후)

[버그 수정]
- 수리하는 동안 맵의 봇들도 총을 못 쏘던 문제를 고쳤습니다. 이제 내 총만 막힙니다.
- 무기 수리 키트가 방어구 수리에 소모되던 문제를 고쳤습니다. 방어구 수리 키트만 씁니다.
- 거의 다 찬 방어구를 조금만 고쳐도 최대내구도가 크게 깎이던 문제를 고쳤습니다. 이제 고친 만큼만 깎입니다.

[새 기능]
- 수리 작업 모션: 발전기 고칠 때처럼 작업 자세를 취합니다. 멈춰 선 상태에서만 시작되고, 작업 중엔 움직일 수 없습니다.
  F12에서 '멀티툴로 작업'(기본) / '쪼그려 앉아 작업' 중 고를 수 있습니다.
- 모션이 싫으시면 F12에서 '레거시 방식 사용 (모션 없음)'을 켜시면 예전처럼 선 채로 수리합니다.
  이때 수리 중 이동은 '느리게 걷기'(기본) / '움직이면 취소' / '제한 없음' 중 선택.
- 진행 상황을 오른쪽에 한 줄로 알려 줍니다 → "전체 수리 완료까지: 63%"
  다 고치면 "방어구 수리 완료", 중간에 손을 떼면 "방어구 수리 중단 · 전체 수리 완료까지: 85%"
  부위별로 자세히 보고 싶으시면 F12 '상세 수리 진행도 표시'를 켜세요.
- 전부 다 고쳐지면 상인 수리 때 나는 '수리 완료' 소리가 한 번 납니다. (F12에서 끌 수 있음)
- F12 설정 화면을 전부 한글로 바꿨습니다.


■ F12 주요 설정 (레이드 방어구 수리)

- 수리 단축키: J
- 한 번에 고치는 양: 30% / 수리 간격: 1초 / 한 번에 쓰는 수리킷 양: 20
- 작업 모션 종류 / 레거시 방식 사용
- 상세 수리 진행도 표시 / 수리 완료 효과음
- 수리하면 최대내구도도 줄어듦 (끄면 최대내구도가 안 깎임)


■ 문제가 생기면

F12 '4. 디버그 → 디버그 로그'를 켜고 한 번 재현하신 뒤, SPT\BepInEx\LogOutput.log 파일을 댓글로 보내 주세요.
